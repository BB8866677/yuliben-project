# 游历本 · 第十七轮（第 09 页旅行纪念品邮局）

本项目为网络与新媒体专业课程的 **React + Vite 手机 App 交互原型**。保留前七页既有功能，第八页已经新增「真实实体书风格的文艺装帧定制」交互；第九页已经完成正式视觉与交互开发，九个主页面均已接入主要模拟交互。

## 使用方法

1. 在 VS Code 中打开本文件夹（`yuliben-project`）。
2. 在终端执行：

   ```bash
   npm install
   npm run dev
   ```

3. 浏览器打开终端给出的本地地址。
4. 推荐测试链路：**AI 规划 → 行程详情保存 → 第六页收集素材生成手账 → 第七页修改并保存 → 点击「制作实体手账」→ 第八页定制 → 创建模拟订单 → 第九页查看。**

直接进入第八页且尚无已保存手账时，会显示空白提示，引导先创建手账，不会生成虚构的用户数据。

## 第八页（本轮正式开发）

- **真实实体书风格的封面预览**：书脊、纸页厚度、布纹 / 牛皮纸 / 奶油艺术纸表面和自然阴影均用本地 CSS/材质图片呈现；书名、封面文字和封面照片来自用户自己的手账或本页编辑。
- **装帧选项**：A5 竖版（14.8 × 21 cm）、18 × 18 cm 方形；鼠尾草布纹精装、复古牛皮纸封面、奶油艺术纸封面。切换后书本外观及**演示金额**同步变化。
- **编辑封面**：自定义标题、副标题；使用默认手绘插画或第六页上传的旅行照片。无需更改第七页的内页。
- **完整内页翻阅**：从本地存储读取第七页已保存的编辑器图层，照片、手写文字、线稿和贴纸均参与预览。支持左右翻页和触摸滑动；方形版**按比例缩放保留全页，不强制裁切**。
- **印刷注意事项**：展示照片像素偏小的提醒、方形版留白提醒与印刷安全提示；不把模拟预览声称为可直接交付的印刷文件。
- **模拟下单**：选择数量（1–5 本）、查看价格明细；创建订单时保存**手账内容快照**，原手账修改不会自动影响旧订单。
- **手机端布局**：整个第八页仍位于与前七页一致的手机框内，封面与预览按手机宽度适配，不使用宽屏工作台。

## 第九页（本轮正式开发：旅行纪念品邮局）

- **复古旅行邮局视觉**：暖米色信纸、邮戳、旅行封面书、手绘寄送路线，统一手机端界面；真正的封面来自第八页的模板/标题和订单快照。
- **订单列表与筛选**：全部、制作中（含待制作）、寄送中、已完成、已取消。没有保存记录时使用手绘空状态，不虚构订单。
- **底部信纸弹层**：在手机 App 内打开；包含真实订单快照封面、编号、创建日期、尺寸、材质、封面模板、数量和模拟金额。支持点击遮罩、关闭按钮、Esc 关闭与下滑关闭。
- **演示进度**：待制作 → 制作中 → 寄送中 → 已完成；用户必须在详情内手动点击推进，变化保存在 LocalStorage。**这些状态不是工厂或物流真实更新**。
- **取消订单**：未寄送前支持二次确认取消；已寄送、已完成、已取消订单不可重复取消或推进。
- **再次定制**：优先寻找原手账，带回原订单的尺寸、封面模板、标题与材质。若原手账已不在当前浏览器，则明确提示，避免错误套到其他旅行。
- **本地问题反馈**：输入意见后仅保存到当前浏览器的订单数据中，不会向客服提交。订单创建时保存的手账图层快照不会因状态/反馈变化而丢失。
- **限制**：没有真实支付、印刷或物流，也没有与客服系统连接。图片仍依赖当前浏览器 IndexedDB，清除浏览器站点数据后可能失去照片。


## 重要限制

- **无真实 AI 服务**：AI 规划、文案生成仍为本地演示逻辑。
- **无真实电商或印刷服务**：金额为课堂示例价，订单只保存在当前浏览器的 LocalStorage，不涉及付款、物流、厂家订单、实际印刷或云同步。
- **非印刷级预检**：未接入专业出血、装订、色彩管理或 DPI 检测，也没有 PDF 印刷文件导出。
- **照片存储**：上传的旅行照片保存在当前浏览器 IndexedDB，订单快照仅存储图片 ID 引用，不把大图片重复复制进 LocalStorage；清除站点数据可能丢失图片或订单。
- **跨版本数据**：尽可能沿用原项目同一域名及端口以保留此前保存的行程和手账；浏览器换端口或清理存储可能无法读取旧数据。

## 第十六轮：第八页 V2.0 · 可旋转 3D 实体书与精美封面

本轮沿用第十五轮的数据与订单逻辑，完整保留前七页。

### 真实三维书本

- 引入 **Three.js**，通过 WebGL 绘制封面、封底、书脊、有厚度的纸页以及柔和阴影（不是静态产品图片或纯 CSS 2.5D）。
- **在手机页面内**手指左右拖动模型可旋转，支持左转、右转和回正按钮；点击“翻阅内页”打开原有手账分页预览。
- A5 竖版与方形实体书具有不同的模型比例。布纹、牛皮纸、奶油艺术纸三种材质改变书壳与书脊的颜色和质感。
- 不能使用 WebGL 的浏览器自动退化为平面封面预览。原有价格、数量、模拟订单和原手账快照不受影响。

### 四套封面 · 同一套动态绘制引擎

- 01 花间漫游（植物水彩）
- 02 旧时光邮局（复古票据拼贴）
- 03 海风来信（水彩海边）
- 04 城市漫游图鉴（城市建筑手绘）

四张绘制素材位于 `public/images/print-covers/`，为文本安全区域留了空间。`src/data/printCoverArt.js` 把选中的模板素材和用户标题、副标题、位置、日期、封面照片绘制到 Canvas 上。这个**同一张 Canvas 贴图**同时用于 Three.js 模型、模板缩略图、平面预览和第九页订单封面，因此避免“好看的预览图与实际显示不一致”。

**如何测试：** 第七页保存手账 → 第八页切换四套封面 → 修改标题和副标题 → 拖动模型 360° 旋转 → 切换尺寸和材质 → 翻阅内页 → 创建模拟订单 → 第九页查看订单快照。

**注意：** Three.js 是新增的 npm 依赖，需要执行 `npm install`。本项目属于课程原型：3D 是网页实时渲染的几何模型，不是工业印刷预制模型；尚不支持真实纸张翻页物理模拟、真实印刷、支付或配送。模拟订单数据保存在当前浏览器 localStorage。

## 第十七轮新增测试建议

1. 第八页创建演示订单，进入 `/orders`，点击「拆开这封旅行来信」。
2. 查看信纸弹层中的封面、规格、金额和制作时间线；推进进度，刷新页面后仍应保持。
3. 对新订单执行「取消订单」并确认；已寄送订单应不能取消。
4. 选择「再次定制」，确认第八页恢复了原模板、材质、尺寸及标题，但不会改动旧订单。
5. 查看手机宽度下的筛选标签和弹层，确认没有横向超出屏幕。

`npm test` 用于运行编辑器及订单存储测试。当前环境未安装项目依赖，完整 React App 的点击、动画与触摸交互仍需在用户本地验证。
